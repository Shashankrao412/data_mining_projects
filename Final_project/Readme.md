# Student Experience & Engagement Survey Analysis

This is my Data Mining project that analyzes student survey data using Python and Machine Learning. The project calculates student happiness scores, finds low-rated facilities, and predicts satisfaction levels.

## Features

- Clean survey data
- Calculate Happiness Score
- Find low-rated facilities
- K-Means Clustering
- Decision Tree Prediction
- Interactive charts with Plotly
- Gradio interface

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Gradio
- Jupyter Notebook

## Project Files

- `DM_finalproject.ipynb` – Main project notebook
- `README.md` – Project documentation
- `requirements.txt` – Required libraries

## How to Run

1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy scikit-learn plotly gradio openpyxl
   ```
3. Open `DM_finalproject.ipynb` in Jupyter Notebook.
4. Run all the cells.

## Output

- Student Happiness Score
- Satisfaction Analysis
- Student Clusters
- Interactive Visualizations
